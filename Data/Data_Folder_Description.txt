This folder contains the data used for all the analysis, in dehydrated form (comment texts and author names removed).
Run rehydrate.py with a YouTube Data API v3 key to restore them; see README.md in this folder.
Specifically, it contains 4 datasets:
1) Dataset_Total: contains ALL comments used in the paper, with their metadata, including stance. Each channel's video info are within a .zip file.
2) active_users.json.zip: contains the comments only of the most active users. For each user, we provide the belonging group, all the comments posted, with toxicity attribute and stance.
3) Training_Data.jsonl.zip: contains the data used for training the ML model for stance detection.
4) Test_Data.jsonl: contains the Gold Set manually labeled we used for testing our model's performance.
